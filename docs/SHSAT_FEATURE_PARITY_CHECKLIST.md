- [ ] 对每个可写操作检查：成功后的数据持久化和刷新反馈、失败/冲突提示、重复点击、返回路径、权限拒绝。所有面向用户的消息必须为英文。

- [ ] 导入数据对账独立记录：试卷、Part/子题型、材料/图片、试题配置与答案、分组顺序、发布、考试记录、答案、计分、报告快照、错题任务及班级归属。源数据本身不完整时标明“源数据问题”，不可直接算迁移丢失。
  **首轮迁移对账（2026-10-27）**：独立源库 `shsat_exam_v2` 的账户/班级/成员/分组/试卷/Part/子类型/材料/题目/计分表/解答/发布/尝试/答案/快照/错题任务数量分别为 `40/5/40/7/47/95/250/1798/4917/3/218/2/12/77/7527/7527/2/21`；目标库 `SHSAT_V2` 映射表对应实体均达到相同源记录数（答案和快照各 7,527 条）。源 ID 映射均唯一；一对一实体映射目标 ID 唯一，答案/快照使用复合目标键因而同一 ID 会重复。目标有 3 份未映射 SHSAT 试卷，确认为验收脚本创建的临时测试卷。来源完整性预检：账号名/班级名/试卷编号冲突均 0，孤立学生或答题引用均 0；但源资源根目录无法找到 30 个素材文件，其中包括 4 个缺图 Hot Spot 题所需图片。逐条对照 77 次尝试的目标状态和成绩结果，68 个已完成、9 个已过期的状态均映射正确；raw、ELA/Math 分数和折算分对照不一致数为 0，答题明细、题目快照均各有 7,527 条，结果 77 条。允许保留缺失素材后执行迁移 dry-run，在既有映射处因源管理员 `user_id=1` 与目标 `admin` 账户记录在导入后发生变化而停止，指纹校验要求人工核对；只读查询确认用户名和账号映射一致，差异涉及账户非敏感信息及密码哈希，未尝试覆盖目标账户。dry-run 未写库，迁移完成门槛保持未关闭。

**结构、内容、答题与成绩快照字段复核（2026-10-27）**：依据 `shsat_import_id_map` 按源 ID 精确关联后，47 份试卷、95 个 Part、250 个子类型、1,798 条材料、3 个评分配置及 218 条评分刻度、2 个解析文件的记录字段均无差异；材料配置、内容、所属分段以及评分刻度均已逐项比对。1,457 个资源引用中，1,427 个本地文件存在，30 个仍引用源系统缺失文件。题目按“源题目 ID＋映射后的源试卷”匹配，4,917 条中 4,916 条与源记录字段一致；唯一差异为源题目 2230：源记录更新时间晚于迁移时间，目标映射记录仍是迁移时的旧版本。目标试卷当前为 READY 且已有历史考试记录，未直接改写题目或解封试卷；该差异按“迁移后源数据变更待人工定夺”处理，不能归为迁移脚本漏字段。另有源管理员和 3 个班级的指纹不同于迁移时快照；管理员账号按既定规则复用目标账号，班级数据不自动回写，避免覆盖统一系统迁移后的变更。7,527 条考试题目快照逐字段对账无差异。答题归档对账发现 370 条的 `selected_answer`/`correct_answer` 被迁移脚本通用 JSON 解析器改成数字类型；已修正转换逻辑，并在目标库事务内恢复这 370 条原始文本值，复核 7,527 条归档记录的这两列均与源库一致。77 条尝试的成绩详情、运行状态和来源元数据快照均与源记录匹配；77 条报告成绩快照及 154 条 ELA/Math 分段结果的总分、分段分数和结果明细逐项复核无差异。30 个源素材缺失及题目 2230 的迁移后源变更仍作为已记录差异。
